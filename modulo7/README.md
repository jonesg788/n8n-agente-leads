# Módulo 7 · Diseño arquitectónico de un sistema agéntico vertical

Pre-entrega: [`PreEntrega_Modulo7_GloriannaAlfonzoJones.pdf`](PreEntrega_Modulo7_GloriannaAlfonzoJones.pdf)

**Vertical:** Sales Ops & Customer Success para una consultora B2B de software y automatización (Sowe). Es un documento de diseño que especializa el agente construido entre el M1 y el M6.

1. Relevamiento, framework de priorización (impacto, viabilidad no-code, adopción y riesgo regulado) y baseline manual (≈ 122 h/mes).
2. Coreografía multi-agente (orquestador + 5 especialistas), contratos JSON, mapa de permisos de mínimo privilegio y context engineering.
3. Propuesta de valor, KPIs con baseline y meta, semáforo verde/amarillo/rojo y protocolo HITL con botones de Slack.
4. Scorecard de leads, scorecard de churn y reclamos, playbook de objeciones y versión de portafolio anonimizada.
